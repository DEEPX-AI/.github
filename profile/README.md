## About DEEPX

DEEPX builds high-efficiency **Neural Processing Units (NPUs)** and the full software
toolchain around them. Our open-source stack, **DXNN® (DX-AllSuite)**, streamlines the
entire journey — from an ONNX or PyTorch model to a real-world "Physical AI" application
running on a DEEPX NPU — through a single, version-aligned toolchain covering compilation,
optimization, and deployment.

- **High efficiency** — the proprietary **DX-COM** compiler extracts full NPU performance with Intelligent Quantization (INT8) that minimizes accuracy loss.
- **Seamless integration** — build vision analytics pipelines with **DX-Stream** (GStreamer-based plugins) without heavy code changes.
- **Flexible ecosystem** — Python and C++ APIs, a **ModelZoo** of 497 optimized models, and workflows for popular frameworks (Ultralytics, PaddlePaddle, RapidAI).

## Get Involved

- **New to DEEPX?** Follow the [Get Started guide](https://developer.deepx.ai/article/get-started/), or install the SDK and demos via [dx-tutorials](https://github.com/DEEPX-AI/dx-tutorials).
- **Building an app?** Explore the C++/Python examples in [dx-app](https://github.com/DEEPX-AI/dx_app) and the pipelines in [dx-stream](https://github.com/DEEPX-AI/dx_stream).
- **Bringing your own model?** Compile it with [dx-compiler](https://github.com/DEEPX-AI/dx-compiler), or pick a starting point from the [ModelZoo](https://developer.deepx.ai/modelzoo/).
- **Want to try natural-language app building?** Check out [dx-agent-dev](https://github.com/DEEPX-AI/dx-all-suite/tree/main/dx-agent-dev-showcase) inside dx-all-suite.
